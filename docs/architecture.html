      hooks/pre-tool-use.js
      
          
      Intercepts destructive shell and git actions before execution across every harness.
      
          
      Blocked flags & commands:
• git push / git commit --amend
• --no-verify / core.hooksPath=
• docker compose down
• rm -rf / sudo
• Warns on files > 800 lines
      
        
      
        
      
          
      hooks/context-ceiling.py
      
          
      Prevents 960k-token runaway sessions by reading the live JSONL transcript tail on every tool call.
      
          
      Thresholds (default 200k):
• 170k tokens: 1x warning injected
• 200k tokens: hard permission deny
Exemptions at ceiling:
• maestri ask / order.py report
• Write/Edit inside runs/<prd>/
      
        
      
        
      
          
      hooks/prod-guard.py
      
          
      Reads `production.markers` from `board.config.json` and blocks direct database writes or destructive ops.
      
          
      Blocked against prod markers:
• Direct SQL / DDL / psql writes
• Destructive container/volume ops
• Unsanctioned SSH mutations
Enforces read-only Rollout tier.
